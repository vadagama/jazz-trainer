# FX-VISION — Базовый процессор эффектов и пространственное микширование

**Дата:** 2026-07-19
**Горизонт:** 1 версия (2–3 недели)
**Статус:** 🟡 Черновик

## 1. Резюме (Executive Summary)

Jazz Trainer воспроизводит аккомпанемент из отдельных сэмплированных инструментов (барабаны, бас, фортепиано, Rhodes, перкуссия), но сейчас они звучат «в вакууме» — без общего акустического пространства, без выравнивания громкости и без фильтрации. Инструменты существуют в изоляции: каждый со своей громкостью, но без ощущения, что бэнд играет в одной комнате.

Добавляем **базовый процессор эффектов** — единую цепочку обработки сигнала, через которую проходят все инструменты. Четыре эффекта (компрессор, эквалайзер, лимитер, ревербератор) плюс панорама формируют законченный аудиотракт: от сухого сэмпла инструмента до финального стереомикса с защитой от клиппинга.

Ключевая ценность: пользователь слышит не набор разрозненных сэмплов, а **живой ансамбль в акустическом пространстве** — бас держит фундамент, тарелки дышат, фортепиано сидит в миксе, а солирующий инструмент пользователя не тонет в аккомпанементе. Для новичка — один выбор пресета и всё звучит хорошо. Для продвинутого — полный контроль над каждым параметром.

## 2. Конкурентный контекст

| Конкурент / Продукт | Обработка звука | Пространство | Пресеты | Контроль |
|---|---|---|---|---|
| **iReal Pro** | Базовый микшер: громкость + pan на трек | Нет реверба | Нет | Только volume/pan |
| **Band-in-a-Box** | 4-полосный EQ + реверб на мастер, компрессор скрыт | Algorithmic reverb (1 тип) | Нет | Слайдеры на мастер |
| **GarageBand** | Полноценный channel strip: EQ, comp, reverb, limiter | Convolution + algorithmic | Есть (жанровые) | Визуальный EQ, плагины |
| **MuseScore** | Нет (только шрифты/сэмплы) | Нет | Нет | Нет |
| **Jazz Trainer (сейчас)** | Нет обработки. Только громкость на инструмент | Нет | Нет | Volume per instrument |
| **Jazz Trainer (цель)** | Полный тракт: HPF/LPF → EQ3 → Comp → Pan/Vol → Room Send → Master Comp → Limiter | Convolution reverb (38 IR) + общая комната | 4 пресета (Dry Studio → Jazz Club) + кастом | Пресет (4 ручки) + Custom (per-instrument + master) |

**Ниша после реализации:** Jazz Trainer — единственный веб-тренажёр джазовой гармонии с полноценным аудиотрактом (comp/EQ/reverb/limiter), общим convolution-ревербом на основе импульсных характеристик реальных помещений и визуальной настройкой пространственного расположения инструментов. iReal Pro и Band-in-a-Box дают звук «из коробки 90-х»; GarageBand требует ручной настройки треков и не специализирован под джазовую практику. Никто не даёт джазовому музыканту пресет «Jazz Club» в один клик.

## 3. Новые функции (Features)

### 3.1. Аудиотракт: цепочка эффектов (FX Engine)

- **Проблема:** Сейчас инструменты подключаются напрямую к `accompBus` → `Destination`. Нет фильтрации (HPF/LPF), нет эквализации, нет компрессии, нет реверберации, нет лимитера. Каждый инструмент звучит «сыро» — бас гудит, тарелки режут слух, фортепиано и Rhodes конфликтуют в средних частотах, тихие ноты теряются, а громкие клиппуют.
- **Описание:** Вводится единая цепочка обработки сигнала для всех инструментов аккомпанемента и солирующего инструмента пользователя.

  **Схема тракта:**
  ```
  Instrument Sampler
    → Instrument Gain (trim)
    → HPF / LPF (optional, per-instrument)
    → EQ3 (low/mid/high, per-instrument)
    → Instrument Compressor (optional, per-instrument)
    → Channel: Volume + Pan (per-instrument)
    → Band Bus (dry mix)
    → Master Compressor (light glue)
    → Limiter (peak protection)
    → Destination

  Instrument Send (pre-fader from Channel)
    → Room Convolver (shared)
    → Room Return Gain
    → Master (pre-limiter)
  ```

  **Ключевые принципы:**
  1. **Общий room convolver** — один на весь бэнд. Не отдельный реверб на каждый инструмент. Это создаёт ощущение единого акустического пространства.
  2. **Pre-fader send** — посыл на реверб снимается до канального фейдера, поэтому уровень реверба не меняется при регулировке громкости инструмента.
  3. **Limiter на выходе** — защита от клиппинга, threshold −1 dB. Не «мастеринг-лимитер», а страховка.
  4. **Чистая логика в ядре** — все вычисления параметров (пороги компрессора, частоты эквалайзера, уровни send) выполняются в `music-core`, без зависимости от Tone.js. Фактическое создание узлов — в адаптере `tone-audio-adapter`.

- **Конкуренты:** iReal Pro — только volume/pan; Band-in-a-Box — только мастер-эквалайзер без поканальной обработки; GarageBand — полный тракт, но требует ручной настройки. Никто не даёт готовый джазовый тракт «из коробки».
- **Приоритет:** P0 (MVP)
- **Слой / Модуль:** `music-core/src/audio/fxEngine.ts` (чистая логика: пресеты, вычисление параметров, структура цепочки) + `packages/adapters/tone-audio-adapter/src/FxChain.ts` (создание и соединение Tone.js-узлов: EQ3, Compressor, Convolver, Limiter, Channel, Gain)
- **Зависимости:** IR-файлы ревербов (уже есть в `apps/web/public/samples/_source/reverbs/`). Требует рефакторинга `ToneAudioAdapter` — замена прямого подключения `accompBus → Destination` на подключение через FX-тракт.

### 3.2. Система пресетов (FX Presets)

- **Проблема:** 30+ параметров эффектов (на каждый инструмент: HPF, LPF, EQ low/mid/high, compressor threshold/ratio/attack/release, reverb send, pan, плюс мастер-компрессор, лимитер, выбор IR) — неподъёмная сложность для пользователя, который хочет просто играть. Нужен механизм, скрывающий сложность за осмысленными пресетами.
- **Описание:** 4 пресета пространства, каждый — полный набор предустановленных параметров для всех инструментов и мастер-шины.

  **Пресеты пространства:**

  | Пресет | IR-файл | Характер | Для чего |
  |---|---|---|---|
  | **Dry Studio** | Nice Drum Room | Сухо, интимно, короткий хвост (0.5–0.8s) | Отработка ритма и точности — слышна каждая нота |
  | **Natural Room** | Small Drum Room / Highly Damped Large Room | Естественно, умеренно (0.8–1.1s) | Повседневная практика — звук как в репетиционной |
  | **Jazz Club** | Vocal Duo / Narrow Bumpy Space | Тепло, живо, средний хвост (1.0–1.4s) | Игра с ощущением живого выступления в клубе |
  | **Custom** | Выбирается пользователем | Ручная настройка всех параметров | Продвинутые пользователи |

  **Пользовательские контролы для пресетов (Dry Studio → Jazz Club):**

  | Контрол | Тип | Значения | Что делает |
  |---|---|---|---|
  | **Space** | Селектор | Dry Studio / Natural Room / Jazz Club / Custom | Выбор пресета — меняет IR, send-уровни, компрессию и эквализацию всего ансамбля |
  | **Room Amount** | Слайдер | 0–100% | Микширует уровень room return относительно dry-сигнала. 0 = полностью сухо, 100 = максимум комнаты |
  | **Band Width** | Селектор | Narrow / Natural / Wide | Ширина стереобазы: Narrow — инструменты ближе к центру; Natural — джазовая рассадка; Wide — разведённые края |
  | **Band Dynamics** | Селектор | Natural / Controlled | Natural — минимальная компрессия, живая динамика; Controlled — более плотный, выровненный микс |

  **Режим Custom** раскрывает две группы расширенных контролов (см. §3.3 и §3.4).

- **Конкуренты:** В GarageBand есть жанровые пресеты, но нет джазовых. iReal Pro / Band-in-a-Box — нет пресетов эффектов. Ниша свободна.
- **Приоритет:** P0 (MVP)
- **Слой / Модуль:** `music-core/src/audio/fxPresets.ts` (определения пресетов как чистые данные: объекты с параметрами) + `music-core/src/audio/fxEngine.ts` (применение пресета → вычисление итоговых значений для каждого инструмента)
- **Зависимости:** 3.1 (аудиотракт). Без тракта пресеты не к чему применить.

### 3.3. Поканальные настройки (Per-Instrument FX)

- **Проблема:** В режиме Custom пользователь должен иметь возможность точно настроить звук каждого инструмента под свой вкус и оборудование (наушники vs колонки, тихая vs громкая игра).
- **Описание:** В режиме Custom для каждого инструмента ансамбля доступны индивидуальные контролы эффектов. Инструменты сгруппированы по семействам для логичной организации UI.

  **Группы инструментов:**
  - **Bass** (Upright Bass, Electric Bass)
  - **Keys** (Piano, Rhodes)
  - **Drums** (Jazz Kit, Funk Kit)
  - **Percussion** (Latin Perc)
  - **User Lead** (солирующий инструмент пользователя — MIDI-вход или выбранный сэмпл)

  **Per-instrument контролы (для каждого инструмента в группе):**

  | Контрол | Тип | Диапазон | По умолчанию | Назначение |
  |---|---|---|---|---|
  | **HPF** (High-Pass Filter) | Слайдер / крутилка | Off, 35–500 Hz | Зависит от инструмента | Срезает низкочастотный гул и грязь |
  | **EQ Low** | Слайдер | −12…+12 dB | 0 dB | Тембр низа: убрать гул или добавить тела |
  | **EQ Mid** | Слайдер | −12…+12 dB | 0 dB | Тембр середины: убрать мутность или добавить тепла |
  | **EQ High** | Слайдер | −12…+12 dB | 0 dB | Тембр верха: убрать резкость или добавить воздуха |
  | **Compressor** | Вкл/Выкл + параметры | — | Зависит от инструмента | Мягкая поканальная компрессия |
  | **Reverb Send** | Слайдер | 0–100% | Зависит от инструмента | Сколько инструмента уходит в общую комнату |
  | **Pan** | Слайдер | −1.0 (L) … +1.0 (R) | Зависит от инструмента | Положение в стереопанораме |
  | **Volume Trim** | Слайдер | −24…+12 dB | 0 dB | Тонкая подстройка громкости (поверх основной громкости инструмента) |

  **Параметры компрессора (при включении):**
  - Threshold: −30…0 dB
  - Ratio: 1:1…10:1
  - Attack: 1–100 ms
  - Release: 50–500 ms

  **Инженерные значения по умолчанию (пресет Natural Room):**

  | Инструмент | HPF | EQ Low | EQ Mid | EQ High | Comp | Reverb Send | Pan |
  |---|---|---|---|---|---|---|---|
  | **Upright Bass** | 40 Hz | +1 dB | −2 dB | −1 dB | Вкл (thresh −20, ratio 2.5:1) | 6% | −0.15 |
  | **Electric Bass** | 40 Hz | +1 dB | −1 dB | 0 dB | Вкл (thresh −22, ratio 3:1) | 4% | −0.05 |
  | **Piano** | 100 Hz | −3 dB | 0 dB | +1 dB | Выкл | 16% | +0.20 |
  | **Rhodes** | 120 Hz | −3 dB | 0 dB | 0 dB | Вкл (thresh −18, ratio 2:1) | 18% | +0.25 |
  | **Jazz Drums** | — | −2 dB | 0 dB | 0 dB | Вкл (thresh −16, ratio 2:1) | 13% | +0.05 |
  | **Funk Drums** | — | −1 dB | +1 dB | −1 dB | Вкл (thresh −14, ratio 2:1) | 12% | +0.05 |
  | **Percussion** | — | −2 dB | 0 dB | 0 dB | Выкл | 16% | −0.10 |
  | **User Lead** | 120 Hz | 0 dB | +1 dB | +1 dB | Вкл (thresh −16, ratio 1.5:1) | 10% | 0.00 |

- **Конкуренты:** GarageBand даёт поканальный контроль, но без джазовых пресетов и без привязки к учебному контексту.
- **Приоритет:** P1 (Custom-режим)
- **Слой / Модуль:** `music-core/src/audio/fxEngine.ts` (применение per-instrument параметров) + UI в `core-settings`
- **Зависимости:** 3.1 (аудиотракт), 3.2 (пресеты — Custom раскрывает эти контролы)

### 3.4. Мастер-контролы (Master FX)

- **Проблема:** Кроме поканальной обработки, нужен контроль над общим миксом: склеивающая компрессия, защита от клиппинга, выбор импульсной характеристики ревербератора, общая громкость.
- **Описание:** В режиме Custom, дополнительно к per-instrument контролам, открывается секция **Master**.

  **Master-контролы:**

  | Контрол | Тип | Диапазон | По умолчанию | Назначение |
  |---|---|---|---|---|
  | **Master Volume** | Слайдер | −24…+6 dB | 0 dB | Финальная громкость микса |
  | **Room IR** | Селектор | 38 IR-файлов из `reverbs/` | Зависит от пресета | Импульсная характеристика общей комнаты |
  | **Room Return** | Слайдер | 0–100% | 16% | Уровень возврата ревербератора в мастер-шину |
  | **Master Comp** | Вкл/Выкл + параметры | — | Вкл | Лёгкая склеивающая компрессия на band bus |
  | **Limiter** | Вкл/Выкл | — | Вкл | Защита от клиппинга на выходе |

  **Параметры Master Compressor:**
  - Threshold: −30…0 dB (по умолчанию: −16 dB)
  - Ratio: 1:1…5:1 (по умолчанию: 1.8:1)
  - Attack: 1–100 ms (по умолчанию: 40 ms)
  - Release: 50–500 ms (по умолчанию: 280 ms)
  - Knee: 0–20 (по умолчанию: 14)

  **Limiter:**
  - Threshold: −12…0 dB (по умолчанию: −1 dB)

  **Параметры по пресетам (Master):**

  | Пресет | Room IR | Room Return | Master Comp | Limiter |
  |---|---|---|---|---|
  | **Dry Studio** | Nice Drum Room | 12% | Выкл | Вкл (−1 dB) |
    | **Natural Room** | Small Drum Room | 16% | Вкл (thresh −16, ratio 1.8:1) | Вкл (−1 dB) |
    | **Jazz Club** | Vocal Duo | 20% | Вкл (thresh −16, ratio 1.8:1) | Вкл (−1 dB) |

- **Конкуренты:** Band-in-a-Box — мастер-реверб и эквалайзер, но без лимитера и компрессора. GarageBand — полный мастер-тракт. Jazz Trainer — джазово-специфичные значения по умолчанию.
- **Приоритет:** P0 (MVP — мастер-лимитер обязателен для защиты слуха пользователя)
- **Слой / Модуль:** `music-core/src/audio/fxEngine.ts` (мастер-параметры) + UI в `core-settings`
- **Зависимости:** 3.1 (аудиотракт), 3.2 (пресеты)

### 3.5. Визуальная панорама: расстановка инструментов (Stage View)

- **Проблема:** Настройка панорамы через числовые слайдеры (−1.0…+1.0) неинтуитивна. Пользователь не видит пространственную картину ансамбля и вынужден настраивать «вслепую».
- **Описание:** В секции эффектов добавляется визуальный элемент **Stage View** — схематичное изображение сцены (вид сверху), на котором инструменты отображаются в виде перемещаемых иконок. Горизонтальное положение иконки = pan, размер/яркость иконки = громкость.

  **Элементы Stage View:**
  - **Сцена:** полукруглая область с подписанными позициями L / Center / R
  - **Иконки инструментов:** 5–6 иконок (Bass, Keys, Drums, Perc, Lead) с подписями
  - **Drag-and-drop:** иконку можно перетащить по горизонтали — меняет параметр Pan соответствующего инструмента
  - **Слайдер громкости** при наведении на иконку
  - **Listen-кнопка:** при нажатии на иконку солирует инструмент на 3 секунды для оценки его положения в пространстве

  **Стандартная джазовая рассадка (пресет Natural):**
  ```
         L            C            R
         ├────────────┼────────────┤
  Perc ●      Bass ●      ● Keys   ● Drums
              (left)     (right)
                       ● Lead
                      (center)
  ```

- **Конкуренты:** GarageBand — панорама через крутилки без визуальной сцены. Ни один джазовый тренажёр не даёт визуальной расстановки. Это уникальная фича.
- **Приоритет:** P2 (усиливает продукт, но не блокирует MVP)
- **Слой / Модуль:** `core-settings` плагин → новый компонент `StageView.tsx`
- **Зависимости:** 3.3 (per-instrument настройки — Stage View меняет те же параметры Pan и Volume Trim)

### 3.6. Плагин настроек: таб «Эффекты»

- **Проблема:** Сейчас настройки (`core-settings`) имеют табы: Основные, Инструменты, Системные, MIDI. Эффектам нужен отдельный таб с понятным интерфейсом.
- **Описание:** Новый таб **«Звук»** (или **«Эффекты»**) в `core-settings`, содержащий:
  1. **Селектор пресета** (Space) — крупно, сверху
  2. **Room Amount** — большой слайдер
  3. **Band Width** — селектор Narrow / Natural / Wide
  4. **Band Dynamics** — селектор Natural / Controlled
  5. **Stage View** — визуальная панорама (§3.5)
  6. При выборе **Custom** — раскрываются:
     - Секция **Master** (§3.4)
     - Секции **Per-Instrument** (§3.3), сгруппированные по семействам
  7. **Кнопка Preview:** воспроизводит короткий грув (2–4 такта) с текущими настройками для быстрой оценки изменений

- **Конкуренты:** iReal Pro — микшер в отдельном окне, но без пресетов. Band-in-a-Box — настройки разбросаны по диалогам.
- **Приоритет:** P0 (MVP — без UI процессором нельзя управлять)
- **Слой / Модуль:** Плагин `core-settings`, новый таб и компоненты
- **Зависимости:** 3.1–3.5

## 4. Улучшения существующих функций

### 4.1. Рефакторинг ToneAudioAdapter: интеграция FX-тракта

- **Проблема:** Сейчас `ToneAudioAdapter` создаёт `soloBus` и `accompBus`, подключая их напрямую к `Destination`. Нет точки входа для процессора эффектов.
- **Описание:** `ToneAudioAdapter` модифицируется так, чтобы:
  1. Инструменты подключались не в `accompBus`, а в **канальные strip'ы** (создаваемые `FxChain`)
  2. `FxChain` собирает цепочку: Gain → HPF → EQ3 → Compressor → Channel → BandBus
  3. Send с каждого канала уходит в общий `Convolver` → Room Return → BandBus
  4. `BandBus` → Master Compressor → Limiter → `Destination`
  5. Сохраняется обратная совместимость: если FX выключен (или пресет не выбран), инструменты подключаются напрямую в `accompBus` как раньше
- **Приоритет:** P0 (MVP)
- **Слой / Модуль:** `packages/adapters/tone-audio-adapter/src/FxChain.ts` + изменения в `ToneAudioAdapter.ts`
- **Зависимости:** 3.1

### 4.2. Миграция настроек громкости инструментов

- **Проблема:** Существующие настройки громкости (`instrumentVolume`) в `core-settings` должны работать совместно с `Volume Trim` из FX-процессора, а не конфликтовать.
- **Описание:** Уточняется семантика:
  - **Instrument Volume** (существующий) — основная громкость инструмента в миксе. Меняется на табе «Инструменты».
  - **Volume Trim** (новый, в FX) — тонкая подстройка относительно основной громкости. Работает как дополнительный gain ±12 dB в канальном strip'е.
  - Итоговая громкость = `instrumentVolume` + `volumeTrim`.
- **Приоритет:** P1
- **Слой / Модуль:** `core-settings` (UI) + `fxEngine.ts` (логика) + `FxChain.ts` (применение)
- **Зависимости:** 3.1, 3.3

### 4.3. Предпрослушивание пресетов в плеере

- **Проблема:** При смене пресета эффектов пользователь должен слышать разницу немедленно, а не гадать.
- **Описание:** При изменении любого параметра эффектов (пресет, Room Amount, Band Width, Band Dynamics) текущий микс обновляется мгновенно — параметры применяются на лету через `Tone.js` без перезапуска транспорта. Для этого `fxEngine` предоставляет метод `applyFxParams(params: FxParams): void`, который обновляет значения существующих узлов.
- **Приоритет:** P0 (MVP)
- **Слой / Модуль:** `fxEngine.ts` + `FxChain.ts`
- **Зависимости:** 3.1

## 5. Не войдёт в эту версию (Out of Scope)

- **Многополосный компрессор (multiband)** — оставляем однополосный для простоты и предсказуемости
- **Сатурация / harmonic exciter** — украшательство, не влияет на базовое качество микса
- **Хорус / тремоло / фленжер на Rhodes** — стилистические эффекты, не базовый тракт
- **Separate drum channels** (kick/snare/hihat/ride отдельно) — пока drums обрабатываются как группа
- **Библиотека пользовательских IR** — только предустановленные 38 файлов
- **Spatial audio / 3D positioning** (Web Audio PannerNode с HRTF) — избыточно для джазового тренажёра
- **Sidechain-компрессия** (ducking бэнда под пользователя) — уже реализована отдельно в `duckingCompressor.ts`, не меняется
- **Экспорт микса в аудиофайл** — задача для отдельной версии
- **A/B-сравнение пресетов** — полезно, но не MVP
- **Автоматический анализ и коррекция частотных конфликтов** — избыточно для первой версии

## 6. Риски и допущения

| Риск | Вероятность | Влияние | Решение |
|---|---|---|---|
| **Tone.js Convolver с длинными IR крашит AudioContext** | Средняя | Высокое | Предзагрузка IR при выборе пресета, а не при старте страницы. Ограничение длины IR до 2 секунд |
| **Много узлов Tone.js → высокая задержка (latency)** | Низкая | Среднее | Канальные strip'ы создаются только для активных инструментов. HPF/LPF и компрессор — опциональны и отключаемы. Минимизация числа узлов в цепочке по умолчанию |
| **38 IR-файлов занимают много места** | Низкая | Низкое | IR-файлы уже на диске (~30 MB суммарно WAV). Для production — конвертация в OGG (~5–8 MB). Загрузка — lazy, только выбранный IR. Мобильная версия (Low Quality) использует Tone.Reverb (алгоритмический) вместо Convolver |
| **Пользователь перегружает микс эффектами → грязный звук** | Средняя | Среднее | Пресеты задают безопасные значения. Custom-режим показывает предупреждение при экстремальных значениях (например, Room Return > 50%). Limiter всегда включён на −1 dB |
| **Stage View (drag-and-drop) требует много UI-работы** | Средняя | Низкое | Stage View — P2, не блокирует MVP. Можно отложить или упростить до статичной визуализации с ползунками |
| **Резкое изменение параметров компрессора во время воспроизведения вызывает audible clicks** | Средняя | Среднее | Применять параметры через `Tone.Param.rampTo()` с временем атаки 10–20 ms вместо мгновенного изменения. Либо применять только в паузе |
| **Low/Mobile режим (Tone.Reverb вместо Convolver) требует отдельной ветки логики** | Средняя | Низкое | Абстракция `ReverbNode` в `FxChain`: в Standard/High режиме — `Tone.Convolver`, в Low — `Tone.Reverb`. Переключение прозрачно для остального кода |
| **[assumption] Tone.js EQ3 достаточно для базовой эквализации** | Низкая | Среднее | Для первой версии EQ3 (low/mid/high с настраиваемыми частотами среза) покрывает 90% потребностей. Если потребуется более точный эквалайзер — миграция на `Tone.EQ` (multiband) в следующей версии |

## 7. Метрики успеха

- **Пользователь выбирает пресет Jazz Club → все инструменты получают общую комнату с корректными send-уровнями:** бас сухой (send 6%), тарелки живые (send 13%), фортепиано в пространстве (send 16%). Звучит как бэнд в клубе, а не набор сэмплов.
- **Room Amount 0% → полностью сухой микс.** Room Amount 100% → максимальный реверб без потери читаемости ритма.
- **Band Width Narrow/Natural/Wide → слышимая разница в стереокартине:** Narrow — всё около центра, Natural — джазовая рассадка, Wide — инструменты на краях.
- **Band Dynamics Natural/Controlled → ощутимая разница в плотности:** Controlled выравнивает тихие и громкие ноты без «задавленности».
- **Limiter предотвращает клиппинг:** при любых настройках громкости пиковый уровень не превышает −0.5 dBFS.
- **Переключение пресетов — мгновенное** (без перезапуска транспорта и audible артефактов).
- **`typecheck` + `lint` + `test` — зелёные.** Новые тесты покрывают: применение пресетов, вычисление per-instrument параметров, граничные значения (HPF off, Compressor off, Room Amount 0%).
- **Существующие тесты проходят:** интеграция FX-тракта не ломает текущее поведение инструментов (dry-режим эквивалентен старому подключению).
- **Документация `docs/FX-PROCESSOR.md`** описывает: архитектуру тракта, таблицу пресетов, per-instrument дефолты, IR-каталог, API `fxEngine`.
