## 1. Резюме

Soul / Neo Soul — медленный качающий грув с «карманом» (pocket), где Rhodes выходит
на ведущую гармоническую роль, бас играет «в кармане» с mute/ghost, барабаны держат
16-е ghost-ноты на snare, а гармония расширяется до 9, 11, 13, sus и slash-chords.
В Amazilia это будет седьмой стиль — самый «современный» по звучанию,
с акцентом на текстуру и пространство.

**Ключевая ценность для пользователя:** выбор Soul мгновенно создаёт
обволакивающий грув с тёплым Rhodes в центре, «качающим» басом в кармане,
snare с ghost-нотами и богатой расширенной гармонией. Пользователь слышит
«настоящий соул/neo-soul» без единой ручной настройки.

## 2. Музыкальный характер стиля

### 2.1. Определяющие черты

| Параметр      | Значение                                                                                          |
| ------------- | ------------------------------------------------------------------------------------------------- |
| **Пульсация** | Straight (swing ratio = 0.5) — ровные 16-е, но с ощущением «кача»                                 |
| **Акценты**   | Backbeat (2 и 4), ghost-ноты на snare между основными ударами                                     |
| **Гармония**  | Расширенная: 9, 11, 13, sus4, slash-chords (F/G, Eb/F). Меньше II–V–I, больше плагальных оборотов |
| **Бас**       | «В кармане» — синкопированный, mute/ghost, октавные скачки, but менее агрессивный чем в funk      |
| **Барабаны**  | 16-е ghost-ноты на snare, мягкий kick, ride в soul — редко, чаще hh                               |
| **Характер**  | Тёплый, обволакивающий, «качающий», чувственный                                                   |

### 2.2. Отличия Soul от Funk

| Аспект                 | Funk                                    | Soul / Neo Soul                                    |
| ---------------------- | --------------------------------------- | -------------------------------------------------- |
| **Темп**               | 100 BPM (энергичный)                    | 70–90 BPM (медленный, качающий)                    |
| **Бас**                | Агрессивный syncopated, октавные скачки | «В кармане» — мягче, больше mute/ghost, меньше нот |
| **Гармония**           | Доминантовая, альтерации                | Расширенная: 9/11/13, sus, slash-chords            |
| **Главный инструмент** | Piano + Electric Bass                   | Rhodes + Electric Bass                             |
| **Барабаны**           | Активный kick, открытый hh              | Ghost-ноты snare, мягкий kick, ride редко          |
| **Перкуссия**          | Ковбелл, конги — акценты                | Шейкер 16-е — непрерывная текстура                 |
| **Тон**                | Драйвовый, резкий                       | Тёплый, обволакивающий                             |

### 2.3. Канонические ориентиры

- **Классический соул:** D'Angelo (_Voodoo_), Erykah Badu (_Baduizm_), Maxwell (_Urban Hang Suite_)
- **Neo Soul:** Robert Glasper (_Black Radio_), Hiatus Kaiyote, Moonchild
- **Барабаны:** Questlove (The Roots) — «пьяный» грув, ghost-ноты, карман
- **Бас:** Pino Palladino — «в кармане», mute/ghost, минимум нот — максимум groove
- **Rhodes:** Robert Glasper, James Poyser — тёплые pads и фигурации, ведущая гармоническая роль
- **Piano:** Robert Glasper — расширенные гармонии, slash-chords
- **Орган:** soul-jazz традиция: swells, pads, текстурный слой

### 2.4. Подстили (для будущих версий)

- **Neo Soul** — текущий целевой дефолт: 80 BPM, slow–medium, Rhodes в центре
- **Classic Soul** — 90 BPM, organ в центре, больше духовой секции
- **Soul-Jazz** — быстрее (100+ BPM), organ + гитара, ближе к funk
- **Quiet Storm** — медленнее (60 BPM), максимум «воздуха», shaker 16-е

## 4. Целевые дефолтные настройки (неавторизованный пользователь)

> **Статус:** черновик. Все значения ниже — **предлагаемые**, не реализованы.
> Они основаны на идиомах соула из скилла `musician` и канонических записях.
> После реализации потребуется прецизионная калибровка.

### 4.1. Глобальные параметры стиля

| Параметр        | Значение                      | Обоснование                                                            |
| --------------- | ----------------------------- | ---------------------------------------------------------------------- |
| **Темп (BPM)**  | 80                            | Медленный качающий грув — «карман», пространство                       |
| **Swing ratio** | 0.5 (straight)                | Soul — ровные 16-е; кач создаётся ghost-нотами и ритмическим смещением |
| **Размеры**     | 4/4                           | Стандартный размер                                                     |
| **Форма**       | 8–16 тактов грува (цикличная) | Neo soul основан на груве, как funk                                    |

| **Vibraphone**             | ❌ off  | 0.60     | `pads`             | —           | —          | —                               |
| **Electric Guitar**        | ❌ off  | 0.65     | `soul-comping`     | —           | —          | —                               |
| **Trumpet (muted)**        | ❌ off  | 0.60     | `brass-fills`      | —           | —          | —                               |

### 4.3. Ансамбль по умолчанию (проект): Trio + Shaker

Для неавторизованного пользователя — уникальный состав, отражающий природу стиля:

| Инструмент          | Громкость | Примечание                         |
| ------------------- | --------- | ---------------------------------- |
| Drums (soul)        | 0.65      | Ghost-ноты snare, мягкий kick      |
| Electric Bass       | 0.70      | «В кармане», mute/ghost            |
| Rhodes              | 0.80      | Ведущий гармонический голос        |
| Percussion (shaker) | 0.55      | Шейкер 16-е — непрерывная текстура |

**Rhodes — самый громкий (0.80).** В соуле это главный инструмент, а не «подушка».
Шейкер включён по умолчанию — непрерывные 16-е создают «воздух» и текстуру.

### 4.4. Баланс громкости ядра (проект)

```
Rhodes (0.80) > Electric Bass (0.70) > Drums (0.65) > Percussion (0.55)
```

Rhodes — главный голос. Бас — «в кармане», не доминирует, но держит фундамент.
Барабаны — тише, ghost-ноты создают текстуру, а не пульс. Шейкер — самый тихий,
непрерывная текстурная линия.

## 5. Требования к партии каждого инструмента (целевые)

### 5.1. Drums — Modern Kit в soul-режиме

**Общая задача:** «пьяный» грув с ghost-нотами — карман, а не time-keeper.

| Элемент           | Требование                                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Snare**         | Основной голос. Backbeat на 2 и 4 — мягкий, не резкий. Ghost-ноты: 16-е между основными ударами, 30–50% громкости от основного |
| **Bass drum**     | Мягкий, не акцентированный. Взаимодействует с басом, но не доминирует                                                          |
| **Hi-hat**        | Закрытый — 8-е или 16-е. Мягкий, не резкий. В soul hh — текстурный элемент                                                     |
| **Ride**          | Не используется. Уступает hh и текстуре                                                                                        |
| **Crash**         | Очень редко — только swell в кульминации                                                                                       |
| **Fills**         | Минимальные. Чаще — вариации ghost-нот, а не томы                                                                              |
| **«Пьяный» грув** | Лёгкое ритмическое смещение (slight-lag) — создаёт ощущение «кача». Не метрономная точность                                    |

**Паттерн (проект):** `soul` — ghost-ноты, мягкий backbeat, slight-lag.

**Важное правило:** барабаны в соуле — **текстура и ощущение**, а не метроном.
Ghost-ноты и «пьяный» грув — определяющая идиома (Questlove).

### 5.2. Bass — электрический бас (electric-bass)

**Общая задача:** «в кармане» — синкопированный, с mute/ghost, минимум нот.

| Элемент             | Требование                                                                                            |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| **Паттерн**         | `pocket` — меньше нот, чем в funk. Не «syncopated» (это funk), а «pocket»: каждая нота на своём месте |
| **Mute/Ghost**      | 40–50% нот — mute/ghost. Создают ритмическую текстуру, а не гармонию                                  |
| **Октавные скачки** | Есть, но мягче, чем в funk. Не прыгает — «плывёт»                                                     |
| **Tension**         | `moderate` — без агрессивных альтераций. Гармония соула — расширенная, но не «dirty»                  |
| **Диапазон**        | E1–G2. Нижний регистр, тёплый                                                                         |
| **Артикуляция**     | Мягкая, с лёгким lag. «В кармане» — ритмически точно, но не жёстко                                    |
| **Форма**           | Грув стабилен. Меньше вариаций, чем в funk — соул держит один грув                                    |

**Паттерн (проект):** `pocket`, tension `moderate`.

**Важное правило:** бас в соуле — **минималистичный**. «Меньше — больше».
Pino Palladino: одна нота в кармане стоит десяти нот не в кармане.

### 5.3. Rhodes — электропиано (ведущий гармонический голос)

**Общая задача:** тёплые pads, комплементарные фигурации и ведущая гармония.

| Элемент            | Требование                                                                                                                    |
| ------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| **Режим**          | `rhodes-soul-form` — адаптивная смена по секциям: verse — pads + фигурации, chorus — stab-accents, bridge — ambient-swells    |
| **Voicing**        | `rootless4` — 4 ноты: 3rd + 5th + 7th + extension (9/11/13). Расширенные гармонии                                             |
| **Ритм**           | Verse: pads (целые ноты) + фигурации (8-е, cycling voicing). Chorus: stab-accents (2 и 4)                                     |
| **Тон**            | Тёплый, с эффектами (chorus/tremolo — будущее). Мягкая атака                                                                  |
| **Динамика**       | 0.80 — самый громкий инструмент ансамбля. Это **главный голос**                                                               |
| **Взаимодействие** | Piano (если включён) — комплементарный: piano играет shell/pads, Rhodes ведёт гармонию. Роли инвертированы относительно swing |
| **Форма**          | Весь ансамбль строится вокруг Rhodes. Он не уходит в solo (solo играет другой инструмент)                                     |

**Паттерн (проект):** `rhodes-soul-form`, voicing `rootless4`.

**Важное правило:** Rhodes в соуле — **ведущий гармонический голос**, не комплементарный
слой. Это фундаментальное отличие от всех остальных стилей.

### 5.4. Piano — фортепиано (комплементарный слой)

**Общая задача:** дополнять Rhodes — shell/pads, не доминировать.

| Элемент      | Требование                                                                                   |
| ------------ | -------------------------------------------------------------------------------------------- |
| **Comping**  | `soul-complement` — shell-voicing, разреженный. Не offbeat-push (как в funk)                 |
| **Voicing**  | `shell2` — 2 ноты: root + 3rd или root + 7th. Прозрачный, не перегружает Rhodes              |
| **Ритм**     | 1–2 атаки на такт. Целые или половинные ноты                                                 |
| **Динамика** | 0.60 — тише Rhodes. Это комплементарный слой, роль которого в других стилях выполняет Rhodes |
| **Форма**    | Вступает в chorus для плотности. Уходит в bridge                                             |

**Паттерн (проект):** `soul-complement`, voicing `shell2`.

### 5.5. Percussion — перкуссия (шейкер)

**Общая задача:** непрерывная текстурная линия — шейкер 16-е.

| Элемент           | Требование                                                                          |
| ----------------- | ----------------------------------------------------------------------------------- |
| **Паттерн**       | `soul-shaker` — шейкер, непрерывные 16-е. Мягкий, «шелестящий» звук                 |
| **Шейкер**        | Основной и единственный перкуссионный элемент. Непрерывная линия — создаёт «воздух» |
| **Конги/ковбелл** | Не используются. Соул-перкуссия — это шейкер и больше ничего                        |
| **Динамика**      | 0.55 — очень тихо. Текстурный слой на заднем плане                                  |
| **Форма**         | Играет непрерывно всю форму (кроме intro и ending)                                  |

**Паттерн (проект):** `soul-shaker`.

### 5.6. Organ — орган (Hammond)

**Общая задача:** soul-jazz традиция: swells и pads.

| Элемент     | Требование                                                                          |
| ----------- | ----------------------------------------------------------------------------------- |
| **Паттерн** | `soul-swells` — медленные swells (громкость нарастает и затухает), плотные подклады |
| **Роль**    | Тембральный контраст к Rhodes. «Церковный» оттенок                                  |
| **Тембр**   | Мягкий drawbar-регистр: 888000000, медленный Leslie (будущее)                       |

**Паттерн (проект):** `soul-swells`.

### 5.7. Vibraphone — вибрафон

**Общая задача:** мелодические hook'и и fills.

| Элемент      | Требование                                                                          |
| ------------ | ----------------------------------------------------------------------------------- |
| **Паттерн**  | `pads` — целые ноты, мягкая атака, vibrato                                          |
| **Роль**     | Мелодические hook'и (короткие запоминающиеся фразы). Fills между вокальными фразами |
| **Динамика** | 0.60                                                                                |
| **Форма**    | Verse: hook. Chorus: counter-melody. Bridge: shimmer                                |

### 5.8. Electric Guitar — электрогитара (clean)

**Общая задача:** мягкий soul-компинг (clean, не overdrive).

| Элемент   | Требование                                                                               |
| --------- | ---------------------------------------------------------------------------------------- |
| **Режим** | `soul-comping` — мягкие аккорды, clean-тон. Не funk-chops (резкие) и не overdrive (блюз) |
| **Ритм**  | Мягкие аккорды на backbeat, fingerstyle                                                  |
| **Тон**   | Clean, с лёгким chorus/reverb (будущее). Тёплый, не агрессивный                          |

**Паттерн (проект):** `soul-comping`, clean-тон.

### 5.9. Trumpet (muted) — труба с сурдиной

**Общая задача:** brass fills (Tower of Power-style).

| Элемент      | Требование                                              |
| ------------ | ------------------------------------------------------- |
| **Паттерн**  | `brass-fills` — короткие фразы-акценты на границах фраз |
| **Роль**     | Духовые fills — не мелодия, а ритмические акценты       |
| **Динамика** | 0.60                                                    |

**Паттерн (проект):** `brass-fills`.

## 6. Динамическая арка формы (Soul, проект)

Соул-форма циклична, основана на груве. Секции различаются плотностью,
а не гармонической структурой.

| Секция             | Такты | Drums                                         | Bass                              | Rhodes                                  | Надстройка                             |
| ------------------ | ----- | --------------------------------------------- | --------------------------------- | --------------------------------------- | -------------------------------------- |
| **Intro**          | 4     | Только hh + ghost snare, без kick             | Mute/ghost, pedal                 | Pads, целые ноты, медленная атака       | —                                      |
| **Verse / Groove** | 8–16  | Soul-грув: ghost-ноты, мягкий backbeat        | Pocket, mute/ghost                | Pads + фигурации (8-е, cycling voicing) | Шейкер 16-е; вибрафон — hook           |
| **Chorus**         | 8     | Плотнее: больше ghost-нот, мягкий crash swell | Активнее: больше нот, меньше mute | Stab-accents (2 и 4), плотнее           | Organ soul-swells; гитара comping      |
| **Bridge**         | 8     | Половина темпа: snare на 3, меньше ghost      | Проще, больше mute, pedal         | Ambient-swells, длинные ноты            | Organ держит pads; труба — brass fills |
| **Solo / Feature** | 16+   | Soul-грув тише на 20%                         | Pocket, проще                     | Pads — поддерживает соло                | Соло ведёт (вибрафон/piano/гитара)     |
| **Vamp / Outro**   | 8+    | Постепенное затухание, только ghost-ноты      | Меньше нот, больше mute           | Pads, затухание                         | Инструменты уходят по одному           |

**Правила контраста:**

- Соул не использует crash для границ секций — переходы через плотность и текстуру
- Verse → chorus: Rhodes переключается pads → stab-accents; organ вступает
- Bridge — момент максимального «воздуха»: half-time, ambient-swells
- Шейкер играет непрерывно (кроме intro/ending/возможно bridge)
- Solo — Rhodes не уходит, а поддерживает pads; соло ведёт другой инструмент

## 7. Что должен слышать неавторизованный пользователь (цель)

1. **Выбирает стиль «Soul»** → автоматически Trio + Shaker (drums + electric bass + Rhodes + percussion)
2. **Слышит:** «пьяный» грув барабанов (ghost-ноты snare, мягкий backbeat),
   бас «в кармане» с mute/ghost, Rhodes — тёплые pads и фигурации (самый громкий
   инструмент), шейкер 16-е — непрерывная текстурная линия
3. **Темп:** 80 BPM, straight (swing 0.5)
4. **Форма:** 8–16 тактов грува, циклически
5. **Пользователь может:** изменить темп (BPM), включить/выключить метроном,
   запустить/остановить воспроизведение, выбрать сетку аккордов
6. **Пользователь НЕ может:** менять состав ансамбля, громкость отдельных инструментов,
   voicing, tension, паттерны, swing ratio. Всё это — дефолты, зашитые в стиль.

## 9. Необходимые новые паттерны/артефакты

| Артефакт                                | Тип                | Описание                                                                        |
| --------------------------------------- | ------------------ | ------------------------------------------------------------------------------- |
| `soul` drum pattern                     | Барабанная клетка  | Ghost-ноты snare (16-е), мягкий backbeat, slight-lag humanize                   |
| `pocket` bass pattern                   | Bass step engine   | Минималистичный: меньше нот, больше mute/ghost, «в кармане»                     |
| `rhodes-soul-form` Rhodes form pattern  | Rhodes mode        | Адаптивная смена pads (verse) → stab-accents (chorus) → ambient-swells (bridge) |
| `soul-complement` piano comping profile | Piano comping      | Shell-voicing, комплементарный к Rhodes (роли инвертированы)                    |
| `soul-shaker` percussion pattern        | Percussion pattern | Шейкер 16-е — непрерывная текстурная линия                                      |
| `soul-swells` organ pattern             | Organ pattern      | Медленные swells, pads                                                          |
| `soul-comping` guitar mode              | Guitar mode        | Мягкий clean-компинг, fingerstyle                                               |
| `brass-fills` trumpet pattern           | Trumpet pattern    | Короткие духовые fills на границах фраз                                         |
| `SOUL_PROFILE` StyleProfile             | StyleProfile       | Полный профиль стиля: ростер, дефолты, tempo, форма                             |
