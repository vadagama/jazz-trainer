## 1. Резюме

Jazz Trainer — не «набор виртуальных инструментов с общим метрономом», а **осмысленный
ансамбль**, где каждый инструмент занимает свою нишу и звучит идиоматически верно для
выбранного стиля. Пользователь выбирает стиль — и получает готовый состав, в котором
ритм-секция держит фундамент, гармонические инструменты компингуют, не перегружая друг
друга, а мелодические голоса ведут тему и импровизацию.

**Ключевая ценность:** партии не дублируют друг друга и реагируют на форму. Это отличает
продукт от MIDI-плееров, где инструменты играют независимые дорожки без ансамблевой логики
(см. конкурентный контекст в [`ARANGEMENT_VISION.md`](ARANGEMENT_VISION.md) §2).

**Видение каталога:** от ядра (piano + бас + барабаны) к полноценному биг-бэнд/комбо-ростеру
с тембральными вариантами (upright/electric, acoustic/electric, muted/open) и, в перспективе,
новыми стилями (blues, soul, neo-soul), идиомы которых уже описаны в скилле `musician`,
но ещё не заведены в `StyleProfile`.

Управление сложностью ансамбля — единая настройка «Активность ансамбля» (4 уровня:
Основа → Грув → Развитие → Интерактив), которая задаёт согласованный профиль для
всего состава: стиль + уровень + темп + размер → профиль ансамбля → политики
инструментов → совместимые паттерны. Это исключает несовместимые комбинации
(например, активные партии всех инструментов одновременно) и сохраняет музыкальное
пространство.

## 2. Принципы ансамбля (инварианты музыкальности)

Эти принципы — «конституция» звучания. Любая партия и любой новый инструмент обязаны им
соответствовать.

### 2.1. Ядро и надстройка

**Ядро ансамбля — piano, бас и барабаны.** Для **всех** стилей именно они несут основную
ритмическую и гармоническую нагрузку. Остальные инструменты (Rhodes, гитара, перкуссия,
вибрафон, орган) — **надстройка**: тембральный контраст, текстура,
мелодические краски. Они **не заменяют** ядро.

### 2.2. Три ниши

| Ниша            | Инструменты                     | Функция                                                                                                                                                                      |
| --------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Ритм-секция** | барабаны + бас                  | Неизменный фундамент любого стиля: пульс, тайминг, гармонический низ                                                                                                         |
| **Гармония**    | piano / rhodes / guitar / organ | 1–2 инструмента одновременно — компинг, voicing. Больше — перегруз                                                                                                           |
| **Мелодия**     | вибрафон / соло (MIDI)          | 1 ведущий голос: тема, контрапункт, импровизация. Вибрафон — **ключевой соло-инструмент** проекта: тёплый универсальный тембр, широкая динамика, естественен для всех стилей |
| **Текстура**    | перкуссия                       | Ритмический окрас поверх барабанов, **не дублирует** их                                                                                                                      |

### 2.3. Комплементарность (не дублировать)

- `bass ≠ kick` — не играют одинаковый ритм, а **сливаются** в единый фундамент;
- `piano ≠ bass` — piano не играет walking в басовом регистре;
- `rhodes ≠ piano` — Rhodes держит pads/texture, не дублирует voicing и не берёт развитый ритм;
- `перкуссия ≠ барабаны` — шейкер не повторяет 16-е хай-хэта, конги не дублируют kick/snare.

Принцип диалога: **один играет — другой поддерживает или молчит**. Во время соло
ритм-секция играет разреженнее, оставляя «воздух».

### 2.4. Регистровый баланс

```
Бас        низкий регистр  (ниже C3)
Piano      средний         (C3–C5)
Rhodes     чуть выше piano  (C4–C6)
Соло       верх            (выше войсингов)
```

Voicing не пересекается с басовым регистром (piano ≥ C3). Регистры не конфликтуют.

### 2.5. Динамическая арка формы

Форма «дышит»: intro тихо/разреженно → verse плотнее → chorus энергично (пик) →
bridge контрастно → возврат → ending затухает. Каждая секция имеет свою плотность,
текстуру и набор партий (подробная матрица — §6).

> Полный музыкальный чек-лист — в скилле `musician` (`.agents/skills/musician/SKILL.md`, §5).

## 4. Роли инструментов по нишам

### 4.1. Ритм-секция

- **Барабаны** — 4-уровневая модель v2 (Atom → Molecule → Cell → Organism). Ride ведёт
  пульс в swing, clave задаёт структуру в latin, kick+бас взаимодействуют. Ghost-ноты,
  акценты, fills на границах фраз. Два кита: Jazz (акустический, мягкий) и Funk (резкий, punchy).
- **Бас** — step-движок (`BassStep`): правила выбора ступеней по гармонии/стилю/tension,
  а не фиксированные ноты. Upright (тёплый акустический тон) и Electric (mute/ghost,
  октавные скачки, «в кармане»).

### 4.2. Гармоническая секция

- **Piano** — ядро гармонии для всех стилей. Две оси: **voicing** (rootless A/B, shell 1-3-7,
  quartal, drop-2) и **comping** (ритмические фигурации по стилю). Оставляет пространство
  для соло, не играет непрерывно.
- **Rhodes** — поддерживающий слой, **не основа**. Тембральный контраст, pads, fills в
  паузах piano. Не берёт развитый ритм. В soul/neo-soul может выйти на ведущую гармоническую роль.
- **Guitar** — Freddie Green (четверти, нижний регистр) в swing; bossa-comping (нейлон)
  в bossa; funk-chops (offbeat) в funk. В комбо с piano — мягче/легче.
- **Organ** — плотные подклады и stabs, soul-jazz грув, педальный бас.

### 4.3. Мелодическая секция

- **Вибрафон** — **ключевой соло-инструмент** проекта. Тёплый, универсальный тембр,
  органично звучащий во всех стилях: от мягкого shimmer в балладах до яркой ритмической
  атаки в latin/funk. Мелодические линии, 2–4-голосные подклады, контрапункт.
  Широкая динамика (tremolo/pedal) позволяет вести и тему, и импровизацию.
- **Соло (MIDI)** — универсальный pitched-инструмент для будущих тембров
  (см. [`MELODIC-PLUGIN.md`](MELODIC-PLUGIN.md)).

> Труба, кларнет и флейта — отложены до будущих версий (см. §9.3).

### 4.4. Текстурная секция

- **Перкуссия** — шейкер (16-е в soul), конги (tumbao в latin), бонго (martillo в salsa),
  треугольник (акценты в ballad). Вступает для плотности в chorus или контраста в bridge.
  Не играет непрерывно всю форму.

## 6. Динамическая арка формы (универсальная матрица)

Ансамбль реагирует на смену секций изменением плотности, тембра и активности.

| Секция         | Характер  | Плотность | Барабаны                          | Бас                     | Piano                       | Надстройка                           |
| -------------- | --------- | --------- | --------------------------------- | ----------------------- | --------------------------- | ------------------------------------ |
| **Intro**      | загадка   | 20–40%    | ride bell / щётки, мин. kick      | two-feel / pedal        | shell, длинные ноты         | соло — тема фрагментарно             |
| **Verse / A**  | уверенно  | 40–60%    | основной грув стиля               | walking / root-5th      | rootless / shell            | гитара Freddie Green; rhodes pads    |
| **Chorus / B** | пик       | 70–90%    | грув + crash, fills               | активнее, октавы        | плотнее, верхние extensions | вибрафон counter-melody; rhodes ярче |
| **Bridge / C** | контраст  | 50–70%    | смена идиомы (cross-stick, щётки) | two-feel / pedal, паузы | quartal, больше воздуха     | новая мелодия; вибрафон shimmer      |
| **Solo**       | простор   | 30–50%    | мягче, ride тише                  | проще, half-time        | разреженный shell, паузы    | соло ведёт; остальные молчат         |
| **Ending**     | затухание | 20–30%    | ride fade, last fill → crash      | pedal, ritardando       | широкий drop-2, арпеджио    | все затихают                         |

**Правила контраста:** не держать одну плотность всю форму; менять текстуры на границах
(вход в chorus — crash + fill, piano shell→rootless, бас two-feel→walking); оставлять «воздух»
для мелодии; bridge — момент неожиданности; финал — ritardando + фермата.

**Для каждой секции — свои клетки/паттерны.** Verse и chorus не используют одну и ту же
барабанную клетку: chorus плотнее, с fills и crash.

## 7. Активность ансамбля (Ensemble Complexity) 🟡

> **Статус:** целевая модель (в разработке). Описывает, как единый регулятор управляет
> сложностью всего ансамбля, исключая несовместимые комбинации партий.

Пользователь обычно хочет не «увеличить сложность баса», а получить более спокойный
или более активный аккомпанемент. Поэтому настройка сложности — **единая для всего
ансамбля** («Активность ансамбля»), а не набор независимых регуляторов на каждый инструмент.

### 7.1. Четыре уровня активности

| Уровень           | Смысл                                  | Клавишные                                           | Бас                                                   | Барабаны                                             | Перкуссия / Гитара                           |
| ----------------- | -------------------------------------- | --------------------------------------------------- | ----------------------------------------------------- | ---------------------------------------------------- | -------------------------------------------- |
| **1. Основа**     | Максимум пространства для ученика      | Shell / Rootless-3, длинные аккорды, простые ритмы  | Основные ступени, половинные и целые                  | Базовый пульс, минимум бочки и малого, без филлов    | Выключена или очень разреженная              |
| **2. Грув**       | Естественный стандартный аккомпанемент | Rootless 3–4, простые синкопы, 1–2 рисунка          | Четверти, аккордовые звуки, простые проходы           | Основной groove, лёгкие вариации, редкие филлы       | Поддерживает groove, не дублирует клавиши    |
| **3. Развитие**   | Активная, разнообразная партия         | Rootless-4, extensions, синкопы и anticipation      | Walking / развитый groove, approach notes             | Ghost notes, comping, вариации, филлы                | Контрритмы, дополнительные текстуры          |
| **4. Интерактив** | Ансамбль реагирует и развивает форму   | Upper structures, voice leading, ритмические ответы | Хроматические подходы, displacement, реакции на фразы | Интерактивный comping, breaks, fills, смена текстуры | Диалоги и заполнение свободного пространства |

Уровень 4 не означает «все постоянно играют много нот». Он даёт больше музыкальных
решений, пауз, реакций и развития формы — иначе получится перегруженный микс.

### 7.2. Принцип: стиль × уровень → профиль ансамбля

Уровень не привязывается к отдельным параметрам напрямую (например, «Уровень 3 →
Ghost Notes = On»). Вместо этого уровень выбирает **согласованный профиль аранжировки
для конкретного стиля**:

```
Стиль + уровень + темп + размер + секция
    → профиль ансамбля
    → политики инструментов (piano/bass/drums/guitar/percussion)
    → совместимые паттерны
    → вариации и humanization
```

Один и тот же уровень даёт совершенно разные партии в разных стилях — идиома
стиля первична:

| Стиль     | Уровень 1 (Основа)                                                      | Уровень 3 (Развитие)                                                      |
| --------- | ----------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **Jazz**  | Половинный бас, ride, foot hi-hat 2 и 4, shell voicing                  | Walking bass, ghost notes, rootless-4 comping, fills                      |
| **Funk**  | Простой bass ostinato, backbeat, 16-й hi-hat без ghost, короткие stabs  | Развитый синкопированный бас, ghost notes, контрритмы                     |
| **Bossa** | Базовый bass pattern, редкий piano/guitar comping, стабильная перкуссия | Синкопированный бас, montuno-подобные фигурации piano, активная перкуссия |

### 7.3. Метаданные паттернов

Каждый паттерн (барабанная клетка, bass step, piano comping) описывается метаданными,
которые позволяют системе выбирать **совместимые** комбинации:

- **`complexity`** — 1..4, минимальный уровень для этого паттерна;
- **`density`** — плотность событий (нормированная);
- **`syncopation`** — степень синкопирования;
- **`variation`** — вариативность внутри паттерна;
- **`tension`** — гармоническое напряжение (отдельное от `complexity` измерение);
- **`role`** — `foundation` | `groove` | `comping` | `fill` | `break`;
- **`sections`** — для каких секций формы подходит;
- **`tempoRange`** — допустимый диапазон темпов;
- **`meters`** — допустимые размеры;
- **`compatibleWith` / `conflictsWith`** — совместимость с другими паттернами.

Это позволяет принимать музыкальные, а не случайные решения:

- активное piano comping → более спокойные drums;
- активная гитара → клавишные становятся разреженными;
- бас с синкопами → бочка частично поддерживает его акценты;
- drum fill → остальные инструменты освобождают конец фразы;
- высокая плотность гармонии → уменьшается ритмическая плотность.

### 7.4. Два режима управления

#### Обычный режим (по умолчанию)

Один переключатель в верхней части экрана:

> **Активность ансамбля:** Основа · Грув · Развитие · Интерактив

На карточках инструментов остаются только: включение, громкость, тембр/набор сэмплов,
паттерн («Авто» либо конкретный паттерн). Все остальные параметры система выставляет
автоматически.

#### Расширенный режим

Для каждого инструмента — относительный offset от уровня ансамбля:

- **Следовать ансамблю** (`offset: 0`) — уровень инструмента = уровень ансамбля;
- **Спокойнее** (`offset: -1`) — уровень инструмента на один ниже;
- **Активнее** (`offset: +1`) — уровень инструмента на один выше;
- **Вручную** — экспертный режим, полный доступ к параметрам.

Пример: пользователь выбрал общий уровень 3, но сделал piano «спокойнее»:
ансамбль: 3, piano: 2, bass: 3, drums: 3.

Полностью ручной режим (независимые настройки каждого инструмента) — только для
экспертов: сочетание Piano 4 + Bass 4 + Drums 4 разрушает музыкальное пространство.

### 7.5. Измерения, управляемые уровнем

Уровень управляет несколькими независимыми измерениями. **Не все** растут линейно
с повышением уровня:

| Измерение                      | Поведение 1 → 4                    | Примечание                                                  |
| ------------------------------ | ---------------------------------- | ----------------------------------------------------------- |
| **Плотность нот**              | Умеренно увеличивается             | Не должна зашкаливать на уровне 4                           |
| **Ритмическая сложность**      | Увеличивается                      | Больше синкоп, полиритмий                                   |
| **Вариативность**              | Сильно увеличивается               | Больше вариантов выбора паттернов на такт                   |
| **Интерактивность**            | Сильно увеличивается               | Диалог, ответы, комплементарность инструментов              |
| **Гармоническая насыщенность** | Увеличивается до стилевого предела | Не все стили терпят upper structures                        |
| **Филлы / переходы**           | Становятся разнообразнее           | Частота растёт умеренно                                     |
| **Humanization**               | **Не зависит от уровня**           | Определяется стилем и инструментом                          |
| **Timing jitter**              | **Не растёт со сложностью**        | Даже уровень 1 должен звучать живо                          |
| **Tension**                    | **Отдельное измерение**            | Простой ритм с напряжёнными аккордами — валидная комбинация |

**Ключевой принцип:** humanization — не сложность. Даже уровень 1 должен звучать
живо: timing, velocity variation и slight lag определяются стилем и инструментом,
а уровень влияет прежде всего на музыкальное содержание.

### 7.6. Защитные ограничители

Пять ограничений предотвращают несовместимые и перегруженные комбинации:

1. **Общий бюджет плотности.** У ансамбля есть лимит событий на такт. Если одна
   партия активнее, другим выделяется меньше пространства.
2. **Распределение ролей.** В каждый момент определяется: кто держит основу,
   кто формирует groove, кто comping'ует, кто может добавить fill.
3. **Phrase awareness.** Вариации происходят по фразам (4, 8 или 16 тактов),
   а не случайно в каждом такте.
4. **Адаптация к темпу.** Уровень 4 при 80 BPM и при 240 BPM не может иметь
   одинаковую плотность. С ростом BPM количество событий автоматически сокращается.
5. **Адаптация к гармоническому ритму.** Если в такте четыре аккорда — бас
   и клавишные упрощают ритм. Если один аккорд держится несколько тактов —
   появляется пространство для развитых линий.

### 7.7. Приоритет настроек (итоговая модель)

Три слоя разрешения конфликтов между настройками:

```
Профиль стиля (StyleProfile)
    → уровень ансамбля (1–4)
    → ограничения темпа и гармонического ритма
    → индивидуальный offset инструмента (-1 / 0 / +1)
    → конкретный ручной паттерн (если задан)
```

Каждый следующий слой уточняет предыдущий, но не может нарушить ограничения,
наложенные более высоким приоритетом.

## 9. Будущие стили (roadmap) 🟡

Скилл `musician` уже описывает идиомы **blues, soul/neo-soul** (профиль во вступлении,
рецепты баса/piano). Их заведение в `StyleProfile` — естественное расширение каталога.
Ниже — целевые ростеры (черновик, требует подтверждения перед реализацией).

### 9.1. Blues

- **Идиома:** shuffle-пульсация (триольный грув), walking bass с ходами I–IV–V и блюзовыми
  подходами, доминантовые voicing (7#9, 7b9, 13, b13), call-and-response, «dirty» тон.
- **Ядро:** барабаны (shuffle) + electric/upright bass + piano (доминантовые voicing).
- **Recommended:** guitar (overdrive), вибрафон (блюзовые фразы), organ.
  > Труба и саксофон будут добавлены позже (см. §9.3).
- **Темп/размер:** medium, 4/4 (12/8 shuffle-фил).

### 9.2. Soul / Neo Soul

- **Идиома:** медленный качающий грув (16-е ghost на snare), бас «в кармане» с mute/ghost,
  Rhodes — тёплые pads и комплементарные фигурации, расширенные гармонии (9, 11, 13, sus,
  slash-chords), вибрафон — мелодические hook'и и fills.
- **Ядро:** барабаны + electric bass + piano/Rhodes (Rhodes может вести гармонию).
- **Recommended:** rhodes, percussion (шейкер — 16-е), вибрафон (мелодия, fills), organ.
  > Труба (brass fills) будет добавлена позже (см. §9.3).
- **Темп/размер:** slow–medium, 4/4.

> **Порядок работы над новым стилем** (из скилла `musician` §7): обсудить состав с
> пользователем → завести `StyleProfile` (ростер, дефолты, swing/tempo) → создать
> стиле-специфичные паттерны (барабанные клетки, bass steps, piano comping) → сверить
> идиомы с каноническими записями → верификация (typecheck/lint/test + музыкальный чек-лист).

### 9.3. Кандидаты-инструменты

**Отложенные (вернуть при расширении):**

- **Труба** (muted/open) — лидирующая мелодия, brass-акценты в funk/soul/blues.
- **Кларнет** — деревянный тембр, контрапункт, диксиленд/камерные составы.
- **Флейта** — воздушный голос для bossa/latin/ballad.

**Новые кандидаты:**

- **Саксофон** (соло MIDI) — ключевой джазовый голос, покрывается движком `soloInstrument`.
- **Clavinet** — для funk/soul (перкуссивный клавишный).
- **Маримба** — расширение mallets-группы (вибрафон + маримба).

## 10. Принципы добавления нового инструмента

1. **Роль прежде тембра.** Определи нишу (ритм/гармония/мелодия/текстура) и как инструмент
   взаимодействует с ядром — иначе он будет дублировать существующие партии.
2. **Идиома по стилям.** Для каждого релевантного стиля — характерный паттерн (сверься с
   существующим материалом того же стиля, не изобретай неестественное).
3. **Плагинный контракт.** Движок — в `music-core`, манифест + sampleRegistry — в
   `packages/plugins/instruments/<name>/` (см. [`INSTRUMENT-PLUGIN.md`](INSTRUMENT-PLUGIN.md) §3).
4. **Регистр и громкость.** Не конфликтуй с ядром; задай `perStyleDefaults` (enabled/volume/pattern).
5. **Ростеры.** Впиши в `instrumentRoster` релевантных стилей (required/recommended/optional/hidden).
6. **Верификация.** `npm run typecheck && npm run lint && npm run test` + музыкальный чек-лист §2.

Спецификация pitched-инструментов — [`MELODIC-PLUGIN.md`](MELODIC-PLUGIN.md);
unpitched (перкуссия/барабаны) — [`RHYTHMIC-PLUGIN.md`](RHYTHMIC-PLUGIN.md).

---

## 11. Метрики успеха

- **Ансамблевость:** партии не дублируют друг друга; во время соло ритм-секция разрежается.
- **Стилевая аутентичность:** выбор стиля даёт узнаваемое звучание без ручной настройки.
- **Полнота ростеров:** каждый стиль имеет корректный required + recommended состав.
- **Регистровый баланс:** нет конфликтов бас/piano/rhodes/соло.
- **Динамическая арка:** форма звучит по-разному от intro к ending.
- **Расширяемость:** новый инструмент = плагин + регистрация + алиасы, без правок логики shell.
- `typecheck` + `lint` + `test` — зелёные.
