# Ассеты лендинга Amazilia

Сюда нужно положить скриншоты продукта (PNG). Пока файлов нет — на лендинге
показываются аккуратные плейсхолдеры (см. `BrowserFrame` с `onError`).

## Что куда положить

| Файл                      | Скриншот                                                              |
| ------------------------- | -------------------------------------------------------------------- |
| `hero-catalog.png`        | Каталог композиций (`/`) — крупные плитки. Используется в Hero.       |
| `feature-ensemble.png`    | Плеер → модалка «Инструменты» (список инструментов со слайдерами).    |
| `feature-styles.png`      | Настройки → вкладка «Инструменты» с переключателем стиля (Funk).      |
| `feature-harmony.png`     | Редактор композиции (Chord Palette / секции).                        |
| `feature-player.png`      | Плеер с сеткой аккордов (напр. Blue Bossa).                          |
| `feature-theory.png`      | Теория — каталог лекций (карточки).                                  |
| `feature-practice.png`    | Упражнения / Карточки — выбор типа (Аккорды/Гаммы/Секвенции).        |
| `feature-midi.png`        | Плеер с виртуальной MIDI-клавиатурой.                               |

## Рекомендации

- Формат: PNG, соотношение ~16:10 (кадрируется `object-fit: cover; object-position: top`).
- Ширина: 1600–2000 px достаточно.
- Тёмная тема приложения — совпадает с тёмным фоном лендинга.
